제자리 번역 지원

Apple 의 온디바이스 번역으로 Safari 웹페이지를 제자리에서 번역하는 확장 프로그램.

시작하기. 앱을 열고 「Safari 설정 열기」를 눌러 확장을 켜고 모든 웹사이트 접근을 허용하세요. 툴바 단추에서 「이 페이지 번역」을 누르면 번역돼요.

자주 묻는 것

  • 번역이 안 돼요: Safari 설정 › 확장에서 켜져 있는지, 그 사이트의 접근이 허용돼 있는지 보세요. 처음 쓰는 언어 쌍은 macOS 가 언어팩을 내려받아야 해서 연결이 필요해요. Safari 자체 화면과 지원하지 않는 언어는 번역되지 않아요.
  • 무료는 어디까지인가요: 툴바 팝업의 「이 페이지 번역」·⌥⇧T·우클릭 메뉴·선택한 글 번역으로 하루 10페이지까지 무료예요. 마우스를 올려 원문 보기와 Option 키로 소리 내어 읽기도 무료예요. Pro 는 횟수 제한이 없고 모든 페이지를 열자마자 번역해요. 한 번 결제하면 평생이고 구독이 아니에요.
  • 번역 켜기·끄기 단축키는 뭔가요: ⌥⇧T(Option+Shift+T)예요. 다른 앱이 같은 키를 쓰면 Safari 설정 › 확장 프로그램에서 바꿀 수 있어요.
  • 구매를 복원하려면: 앱의 Pro 에서 「구매 복원」을 누르세요.
  • 번역을 끄고 싶은 사이트가 있어요: 툴바 팝업에서 그 사이트를 끌 수 있어요.
  • 개인정보: 페이지 내용은 Mac 밖으로 나가지 않아요. 자세한 내용은 개인정보 처리방침을 보세요.

시스템 요구사항: macOS 26.4 이상, Safari.

보증과 책임. 이 앱은 있는 그대로 제공되며, 법이 허용하는 최대 범위에서 명시적이거나 묵시적인 어떤 보증도 하지 않습니다. 데이터의 손실·손상·변경, 동기화 실패, 결과의 부정확함, 업무 중단을 포함해 앱의 사용 또는 사용 불능으로 생긴 모든 손해에 대해 법이 허용하는 최대 범위에서 책임을 지지 않습니다. 중요한 데이터는 직접 백업해 주세요. 앱 사용에는 Apple 표준 최종 사용자 사용권 계약이 적용되며, 이 내용은 법으로 배제하거나 제한할 수 없는 이용자의 권리에는 영향을 주지 않습니다. 번역은 자동 생성되며 정확함을 보장하지 않습니다.
